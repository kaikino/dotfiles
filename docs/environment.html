The palette

Terminals colour output through 16 numbered ANSI slots. Ghostty defines what those slots mean; everything else — the prompt, diffs, ls, fzf, lazygit — names a slot (red, bright-black) rather than a hex value. Change the block in ~/.config/ghostty/config and the whole machine follows.

Ground is #0B1020, cursor and every "this is the one" signal are oxblood #B84A4A, structure and metadata are slot 8 grey. Window is 90% opaque with blur; font is Hack Nerd Font Mono at 13px with 12% extra leading.

Four places hold hex directly because they can't read ANSI names: cmux's pane and sidebar colours, the Claude Code statusline, delta's diff-row backgrounds, and the AeroSpace window border. If you re-theme, those need touching too.

What runs when a shell opens

~/.zshrc is deliberately three lines of real config. It sets PATH for jenv, then sources two files in order:

~/.config/zsh/theme.zsh   # tracked — prompt, colours, aliases, tool init
~/.config/zsh/local.zsh   # untracked — this machine only (wake-pc, power-pc)

Inside theme.zsh, order matters and is commented:

StepWhy it's there
XDG_CONFIG_HOMEOne config root at ~/.config. lazygit and lazydocker would otherwise write to ~/Library/Application Support, which doesn't travel.
mise activateHooks cd so node/python switch per directory.
starship initThe prompt.
fzfBinds Ctrl-T and Alt-C, fed by fd.
atuin initLoaded after fzf so it wins Ctrl-R. Up-arrow left alone.
aliasesEach guarded by command -v, so a machine without the tool degrades to the plain command.

Nothing in that file changes what a command does — with one exception: cat is a function that routes flag-led calls (cat -v) to the real cat and bare files to bat.

└─>
~/dev/api
Directory, trimmed to the repo root or last three segments. …/ prefix when trimmed.

Git branch, gold.
*2 ^1
Dirty state, in red so it catches the eye: * modified, + staged, ? untracked, ^ ahead, v behind, ! conflict, = stash.
docker: / k8s:
Context — only in directories with Docker/k8s files, and only when off the default context.
node / java / py
Runtime version — only where a real project marker exists (package.json, pom.xml…). A stray .js file no longer triggers it.

Duration of the last command, when over 2s.
04:12
Clock, right-aligned.
>
Blue when the last command succeeded, red when it didn't.

Config: ~/.config/starship.toml. Keybindings and colours are ANSI names.

Git

git diff, log -p, show all pipe through delta: line numbers, syntax colour from the palette, removed rows on a dark-red wash and added rows on dark-green. n/N jump between files in the pager. merge.conflictstyle is zdiff3, so conflicts show the common base too.

lazygit (lg)

docker ps and docker images print trimmed columns — name, status, ports, image — set in ~/.docker/config.json. That file is not in dotfiles: its auths block is where registry tokens land.

lazydocker (lzd)

Containers, images, volumes, and compose services in one screen. Enter on a container shows logs; [ ] switch to stats, config, top; d removes, s stops, r restarts. x for the full menu on anything. Docker Desktop has to be running for it to see anything.

Runtimes: mise and jenv

Two managers, on purpose. jenv still owns Java — you have JDK 17 and 25 registered, and ~/.java-version sets the global default. mise handles everything else per directory, and is told to ignore .java-version so the two never fight.

mise pins nothing globally: Homebrew's node (26.x) is the fallback, and mise only takes over when a directory says otherwise. To pin a project:

# in the project
mise use node@22        # writes mise.toml, installs 22 if missing
node --version          # v22.x here, v26.x outside

It also honours .nvmrc and .node-version if a repo already has one. mise ls shows what's installed; mise doctor if anything looks off.

Heads-up. Node was force-bumped from a broken 25.8 to 26.8 today. If a project needs 22 or 24, pin it with mise as above rather than fighting Homebrew.

Remote sessions

The remote box's own dotfiles decide what its prompt looks like — nothing here changes that until the dotfiles repo is applied there. What is local: while ssh or mosh is running, the window background washes from navy to dark oxblood, and restores on exit. Local versus remote is answerable without reading anything.

mosh is installed on this side. It needs mosh-server on the far side (apt install mosh on the PC) before it works; then mosh kai@… gives you a session that survives sleep and network changes.

The wake-pc and power-pc aliases moved to ~/.config/zsh/local.zsh — sourced, but outside the repo, because they carry Tailscale addresses and a MAC.

Desktop: Raycast and AeroSpace

Raycast

Spotlight replacement on ⌘Space (set during onboarding; Spotlight's own shortcut has to be unchecked in System Settings if Raycast doesn't do it for you). Clipboard history is the feature to enable first. No config file — it lives in the app.

AeroSpace

Tiling window manager: windows never overlap, each new one splits the space. Not launched yet — first run asks for Accessibility permission and re-tiles everything open. Everything is on ⌥ (Option):

⌥⇧ h j k lMove the window that way.
⌥ 1–9Go to workspace.
⌥⇧ 1–9Send window to workspace and follow it.

Focused window gets a 4px oxblood border, others navy — that's JankyBorders, started by AeroSpace. System Settings, Finder, and Activity Monitor float instead of tiling; add more at the bottom of ~/.config/aerospace/aerospace.toml.

Dotfiles with chezmoi

Every config on this page is tracked in a git repo at ~/.local/share/chezmoi, pushed to github.com/kaikino/dotfiles. chezmoi keeps two copies of each file: the live one you use, and the repo one git knows about. The workflow is three commands:

# 1. edit the live file as normal, e.g. ~/.config/starship.toml
chezmoi re-add ~/.config/starship.toml   # 2. copy the change into the repo
chezmoi git -- commit -am "message"       # 3. commit, then push
chezmoi git -- push

chezmoi diff shows anything the live files have that the repo doesn't. chezmoi cd drops you into the repo directory in a subshell (exit to come back).

On a new machine

brew install chezmoi starship eza bat git-delta fzf btop lazydocker \
             lazygit ripgrep fd atuin mise gh mosh
brew install --cask font-hack-nerd-font raycast nikitabobko/tap/aerospace
brew install FelixKratz/formulae/borders
chezmoi init --apply https://github.com/kaikino/dotfiles.git

On Linux, swap brew for the distro's packages; the shell config degrades cleanly wherever a tool is missing. The README in the repo carries the same list.
